## Applications

### Any Alarm - QR, Math, GPS, etc.

**Any Alarm** is an advanced alarm application designed for people who have difficulty waking up using conventional alarms.

Instead of relying only on a normal snooze button, the application can require the user to complete wake-up challenges such as:

- GPS/location-based tasks
- Mathematical problems
- QR/barcode scanning
- Other challenge-based alarm mechanisms

Google Play:

https://play.google.com/store/apps/details?id=com.aznenterprises.anyalarm

### NET Expense Manager & Tracker

**NET Expense Manager & Tracker** is an offline-capable personal expense and budget management application.

Features include:

- Daily expense and budget tracking
- Visual analytics
- Offline functionality
- Meal tracking
- Tools intended for students and professionals

Google Play:

https://play.google.com/store/apps/details?id=com.aznenterprises.tracksmith

### MineSaves: MCPE World Backup

**MineSaves** is a local file utility for Minecraft Bedrock Edition players.

It is designed to help users:

- Manage Minecraft Bedrock world backups
- Keep local copies of worlds
- Organize saved worlds
- Use custom thumbnails for worlds

Google Play:

https://play.google.com/store/apps/details?id=com.aznenterprises.mcpebackup
