# Muhammad Azaan M R

I am **Muhammad Azaan M R**, an independent mobile app and web developer and creator from **Kerala, India**. I develop Android applications under my developer brand **AZN Labs**, which is also associated with **AZN Enterprises**.

My main focus is building practical software utilities that solve everyday problems, with an emphasis on **privacy, offline functionality, user control, and useful features**.

## My Applications

I have developed and published several Android applications on the Google Play Store.

### Any Alarm - QR, Math, GPS, etc.

**Any Alarm** is an advanced alarm application designed for people who have difficulty waking up with conventional alarms. Instead of relying only on a standard snooze button, it can require users to complete wake-up challenges such as **GPS/location tasks, mathematical problems, and QR or barcode scanning**.

Google Play:  
https://play.google.com/store/apps/details?id=com.aznenterprises.anyalarm

### NET Expense Manager & Tracker

**NET Expense Manager & Tracker** is an offline-capable expense and budget management application. It provides **daily expense tracking, budgeting, visual analytics, and meal tracking**, making it useful for students and professionals.

Google Play:  
https://play.google.com/store/apps/details?id=com.aznenterprises.tracksmith

### MineSaves: MCPE World Backup

**MineSaves** is a local file utility for **Minecraft Bedrock Edition** players. It helps users manage local world backups, organize saved worlds, and use custom thumbnails.

Google Play:  
https://play.google.com/store/apps/details?id=com.aznenterprises.mcpebackup
